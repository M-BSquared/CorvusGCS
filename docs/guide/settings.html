Tools

Settings

SET at the bottom of the left rail. Everything applies at once and is saved, in ~/.corvus/config.json. This page goes through the sections in the order they appear.

Appearance

Company logo
A PNG of your own, shown in the top right of the window.
Colour theme
Six themes, two light and four dark: Light (the default), Light Orange, Blue, Green, Orange and Pink. Switching is instant, with no reload and no flash, and the map, the plots and the instruments all follow.
Interface size
One slider from 80 % to 150 % that scales the whole app, for a small laptop screen or a bright field where you want everything larger.
Units
A unit system (metric, imperial, aviation) that sets altitude and length, distance, speed and temperature at once, and each of the four on its own afterwards. Units are for display only: parameters, mission files and everything sent to the aircraft stay in the units the autopilot uses.
Pages
Adds MISSION under HOME in the left rail. Off by default. See Mission planner.

Map service

Which map service and which of its layers. It can also be switched from the layer control on the map itself.

ServiceKey
Esri, OpenStreetMapNone needed.
Google, BingWork without a key, and take one if you have it. With a key, tiles come through the licensed APIs (the Google Map Tiles API, which has to be enabled for the key, and the Bing Maps REST API with a Bing Maps for Enterprise key), and the service card says "licensed API".
MapTiler, MapboxNeed a key. A free key from either gets you licensed satellite imagery and street maps on your own quota. They appear as a service once they have a key; until then the note under API keys names them.

API keys is the button that takes a key. The key never reaches the browser: Corvus fetches the tiles itself and hands the images to the page, so the key stays in the config file (readable by you alone), never appears in a page, a URL or a log line, and is never sent back out by the API. The Settings page is only told that a key is saved. You will not see it again after saving; REMOVE clears it.

Flown track
Earlier flights in their own colour (on by default), and clearing the track whenever Corvus starts or the autopilot reboots (off by default). See The flown track.
Controls
The virtual joystick, arrow keys and WASD keys, each its own switch and all off by default, and the key strength slider. See Manual controls.
Flight bar
Shrink with the window, off by default. On, the ARM, TAKEOFF, LAND, RETURN and PLAN bar steps down as soon as it would cover more than half the map: to the width of each word first, then to icons alone. It is measured on the map itself, so opening the side panel narrows it just as shrinking the window does.
Flight HUD
Show the flight HUD, on by default. Off, the window with the compass, the attitude indicator and the readouts is taken off the Home map. Turned back on, it returns where you left it. See The flight HUD.
Compass
Lock compass nose up. Off, the compass is north up; on, the rose turns and the top of the dial is always the aircraft's heading.
Top bar
Status dots, off by default: a dot after the VEHICLE, STATUS, GPS and BATTERY captions, green good, amber caution, red fault, grey nothing to report. The values already carry that colour; the dots let you scan the bar by colour alone.
Notifications
Severity marks, off by default: coloured bars above and below the level icon of a notification, blue for information, amber for a warning, red for a fault.
Camera and terminal windows
Open inside the Corvus window (off by default) and Solid terminals. See Floating windows.
App icon
Inverted app icon uses the black mark instead of the white one for the Dock (macOS) or taskbar (Linux), better on a light dock. Icon backplate draws the mark on a filled rounded square so it is visible on a dock of any shade. Neither changes anything but the icon.

SSH Connections

Add, connect and remove saved SSH hosts. The same list is used by the SSH tab and the launcher plugins.

Connection

Shows the saved MAVLink connection and the HTTP port. To change the link, use the LINK tab (see Connect to the aircraft).

Files

Parameter export folder: where Export writes parameter files. Leave it empty for ~/.corvus/params; the export dialog can still choose another place per file. The other folders Corvus uses are set in the config file; see where Corvus keeps its files.

Parameter defaults

Keep a copy on this computer, off by default. The parameter editor reads each parameter's default from the vehicle, and on PX4 that file can take half a minute over a telemetry radio. With this on, Corvus keeps a copy per firmware and reuses it whenever the vehicle reports the same checksum for its file. ArduPilot always reads from the vehicle.

A copy is matched to the vehicle by a checksum only, and in rare cases two different files share one. The defaults, descriptions and ranges shown would then belong to another firmware. If defaults ever look wrong, clear the copies and switch this off.

Analysis

Sensitivity of the flight review: Relaxed, Normal or Strict. See Sensitivity.

Plugins

What Corvus found in both plugin folders, and Open plugin folder, which opens your own. See Plugins.

Export and import

The settings of the station in one JSON file, for a backup or for setting up the next laptop. That includes the window layout (where the flight HUD and the virtual joystick sit), the RC transmitter bindings, the checklists, the plugins and the company logo.

  • By part. Both directions go by part (interface, window layout, map, connections, vehicle, folders, plugins), with All and None to start from. A part left out of the file is never touched on import.
  • Plugins by plugin. Under Plugins you choose, per plugin, its Settings and its Files (the plugin itself, for one you installed). The plugins that ship with Corvus are on every station already, so only their settings travel.
  • Secrets stay out, unless you switch them on: passwords and map keys are not in the file by default, and an import without them keeps the ones already stored for the same host.
  • Import shows what the file holds, warns before it installs plugin files, and is refused while the aircraft is armed.

About

The version, the live connection summary, and Credits, which lists every bundled component and its licence.

Updates

A switch, on by default, that compares the running version with the published releases on GitHub and shows a notice when a newer one exists, plus Check now. SET in the left rail carries a marker while a newer release is waiting.

  • Nothing is downloaded and nothing about your machine is sent.
  • With no internet the check fails silently.
  • The notice never appears while the aircraft is armed.
  • Skip this version stops it coming back for that release.
